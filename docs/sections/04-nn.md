## 室友人脸识别案例讲法（5—7分钟）

1. **约1分钟｜定义问题与边界。** 指着照片介绍“课堂虚构故事”：笑雨与骐源是室友，整理共同相册时发现逐张按人物归类很费时间，于是把需求限定为三分类——笑雨 / 骐源 / 其他。两人先约定照片仅用于课堂实验，不接门禁、不做身份认证，并取得数据使用授权。
2. **约1—2分钟｜走训练与测试流程。** 强调一张照片不足以代表一个人；笑雨与骐源都需要角度、光线、表情不同的照片，其他人物照片组成“其他”类。把前面的数字神经网络原样迁移：像素输入、多层表示、归一化概率、损失、反向传播；再用未参与训练的照片检查模型是否只是记住训练样本。
3. **约1分钟｜讲关键设计。** 模型的世界被刻意缩成笑雨 / 骐源 / 其他三类：既要分清两位室友，也要学会拒绝圈外人物；最大概率低于0.70则不硬猜。强调置信度不是身份事实，阈值只是应用规则。
4. **约1—2分钟｜模型亮相。** 点击“让模型认认笑雨”运行内置照片；若时间允许，再请现场学员换一张照片对比三类概率。
5. **约30秒｜收束。** 模型能把像素映射到预设类别，却不知道“室友”是什么，也不理解照片背后的场景和关系；识别内容不等于理解语言、制度或业务，由此过渡到大语言模型。
