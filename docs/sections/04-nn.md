## 室友人脸门禁案例讲法（5—7分钟）

1. **约1分钟｜定义问题与边界。** 指着照片介绍“课堂虚构故事”：笑雨与骐源是室友，想为自己的公寓做一个简易人脸门禁。需求限定为三分类——笑雨 / 骐源 / 其他；识别为两位室友且达到阈值时模拟开门，其他或低置信度结果保持关闭。两人取得彼此的数据使用授权。
2. **约1—2分钟｜走训练与测试流程。** 强调一张照片不足以代表一个人；笑雨与骐源都需要角度、光线、表情不同的照片，其他人物照片组成“其他”类。把前面的数字神经网络原样迁移：像素输入、多层表示、归一化概率、损失、反向传播；再用未参与训练的照片检查模型是否只是记住训练样本。
3. **约1分钟｜讲关键设计。** 模型只输出笑雨 / 骐源 / 其他三类概率；门是否打开由模型之外的程序规则决定。最大概率低于0.70则不硬猜、不开门。说明误放与误拒的不同后果，并强调置信度不是身份事实。
4. **约1—2分钟｜模型亮相。** 点击“用笑雨照片测试开门”运行内置照片，观察预测标签、三类概率和模拟门禁动作；若时间允许，再换一张其他人物照片，观察门保持关闭。
5. **约30秒｜收束。** 模型能把像素映射到预设类别，却不知道“室友”是什么，也不能独自构成安全门禁；真实系统还需活体检测、防照片攻击、安全存储、故障回退和备用开门方式。识别内容不等于理解语言、制度或业务，由此过渡到大语言模型。
