# 01 · problem — 导言（Introduction）

- **锚点：** `#problem`
- **侧栏：** 导言（5′）— 置于「第一部分」标签之上，与正文结构一致
- **标题：** 导言

## 教学目标

- 用 `CourseArchitecture` 交代课程主题，并把三部分作为整堂课的唯一顶层骨架明确展示
- 用国内常见智能体平台的真实公开界面看板建立兴趣；点击切换时同时看到工作台形态、常见能力与可交付成果，明确这里只做兴趣引入，不做产品排名或技术定义
- 用「主要收获」明确学完后应带走的判断能力

## 内容块

1. `SectionTitle` — 导言（无副标题 intro）
2. `CourseArchitecture` — 开场说明 + 三部分总体架构；第二、第三部分均标为核心，合计约60分钟
3. `ChinaAgentPlatformGlance` — 「中国主流智能体平台」可视化看板，约1分钟；默认选中扣子 Coze，左侧缩略图墙可切换阿里云百炼、文心智能体平台、腾讯元器与 Kimi；中央展示对应工作台/对话/编排界面大图，右侧同步更新一句定位、四条短能力点和一句「能交付什么」；移动端改为缩略图横滑 + 主图 + 能力区纵向排列
4. `content-block.lesson-takeaways` — 「主要收获」四格（无小标题）
5. `TeacherNote` — 现场只需切换两三个代表界面，再回到课程地图，不逐个平台展开
