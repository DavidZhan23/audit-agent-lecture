**顶层架构：** ① 技术基础 → ② 智能体基础与架构 → ③ 智能体在审计中的应用

## 当前课程事实

| 项 | 当前设计 |
|---|---|
| 第一部分 | `#code`—`#llm`，53分钟；规则→机器学习→神经网络→大语言模型；05用合同示例串起神经网络机制、文字数字化、Transformer整体/Block/输出、预训练、指令训练和接口产品层，再区分模型、调用接口、应用与智能体；神经网络章节含“两位室友搭建人脸识别器”5—7分钟案例支线 |
| 第二部分 | `#agent`—`#agent-value`，47分钟；八章讲清行动缺口、定义与结构、运行循环、知识型/任务型/规划型智能体、组合案例、价值与边界 |
| 第三部分 | `#audit`—`#audit-governance`，60分钟；章节14—19，以异构资料解析、智能问数与数据分析、审计报告生成三个启发式案例组成完整审计链 |
| 演示形式 | 第一部分保留代码实验；第二、第三部分以图示与互动演示为主，不展示代码栏 |
| 阅读方式 | 23页课件模式；正文与底部翻页控制区分离，不遮挡内容；侧栏可显隐 |
| 审计交付 | 可复核疑点证据包，不是风险分或自动结论 |
| 审计项目 | 采购与合同管理专项审计；沿资料解析、平台问数和报告生成形成证据链 |
| 主实现 | `app/page.tsx`（`Home`） |

任何教学结构变化都必须同步更新本目录；详细约束见 `.cursor/rules/lecture-docs.mdc`。
